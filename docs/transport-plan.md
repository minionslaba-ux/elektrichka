# Транспорт по миссиям — предложение (ждёт «да» владельца)

Просьба владельца (18.11.2026): «в каждой миссии должен быть разный транспорт».
Правило, которое предлагаю: внутри главы транспорт не повторяется; «Буханка» — не больше одной миссии на главу (обычно босс, где нужен дед в турели).
Модели — из того, что уже есть в игре (Kenney: ховербайки, болид, тягач, багги, комбайн, челнок, корабли; свои: Гоша, лама, лодки и т. д.).

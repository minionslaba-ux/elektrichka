# План замен миссий в главах 8–14 (на согласование владельцу, код — после «да»)

Правила — скилл `raznoobraznye-missii`. Остаются миссии, которые уже разные (гонка на тарелке, погоня за газовозом, бегство от трещины, «Гюйгенс», буксир «Лунохода», прыжок через борозду, пастух, хрупкий груз). Заменяются «сбор» и «удержание», а боссы получают свои механики.

**Новые движки** (каждый — на 3–5 миссий в разных главах):
1. **Мини-игра поверх мира** — уже есть в игре: «Повтори», ритм, викторина, «Лента»; содержание своё для каждой главы.
2. **Выбор с последствиями** — разговор, где ответ меняет следующую миссию или босса.
3. **Слежка** — конус обзора и шкала «подозрения».
4. **Стелс-кража** — шум от скорости, охрана с обходом.
5. **Переключатели** — порядок вентилей или шлюзов, ограничено число ходов.
6. **Пешая вылазка** — бабуля выходит из «Буханки» и идёт пешком с фонариком.
7. **Фотоохота** — режим камеры, цель видна несколько секунд.
8. **Оборона с постройкой** — между волнами ставишь заграждения.

# «Бабуля на Марсе» — правила работы

- Отвечать владельцу по-русски, просто; честно говорить, что проверено, а что нет.
- Половина игроков — на слабых Android (Mali-G52/G57, 2–4 ГБ): первая картинка меньше чем за 2–3 с, на старте загружается не больше 3 МБ, ≤ 150 тыс. треугольников в кадре, мало вызовов отрисовки, без динамических теней (свет запекается в цвет вершин), облегчение графики по fps.
- Старт не зависит от внешних CDN (свои копии в `lib/`); всё, что не нужно для первого экрана, грузится после него.
- Первый заезд стартует сам за 1–2 с с короткой подсказкой.
- Реклама только по желанию игрока, между заездами, не чаще раза в 4 минуты и не после первого заезда; во время езды рекламы нет.
- Статистика: Supabase (общий проект с «Ночным тарифом»), только свои таблицы с отдельным префиксом; таблицы `nf_*` не трогать.
- Не копировать чужие игры (названия, персонажей, модели, интерфейс).
- Перед выкладкой: Playwright (`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`, Pixel 5 + компьютер), замер загрузки, треугольников и вызовов отрисовки, ошибки в консоли. Записать в `docs/obnovleniya.md`.
- Ничего не публиковать в каналах владельца без его согласия.
- Новые миссии и сцены собирать из моделей и звуков Kenney (CC0), которые уже есть в игре (`assets/kn_*.bin`, `assets/sfx/`, `assets/fx/`), — так по просьбе владельца. Свои процедурные модели — только для главных героев и того, чего нет у Kenney. Новые паки — через упаковщик в цвета вершин, авторство — в `CREDITS.md`.
- Миссии, главы, задания, боссы — только по скиллу `.claude/skills/raznoobraznye-missii` (каталог `docs/missii-katalog.md`, таблица новых миссий владельцу до кода, проверка `check_missions.py`).
- Пропорция владельца: миссий «езда и стрельба» (тип `бой`) — не больше 20% по всей игре. Она важнее правила скилла про типы; проверять долю по строке «Типы по всей игре» в выводе `check_missions.py`.

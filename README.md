# Бабуля на Марсе (рабочее название)

Браузерная 3D-игра: бабуля в турбо-кресле дрифтует по марсианской колонии и везёт внукам картошку.
Открыть: `index.html` (любой статический хостинг). Журнал изменений и как проверено: `docs/obnovleniya.md`.

Сторонний код: three.js r147 (MIT), `lib/three/three.min.js`. Модели свои, процедурные.
